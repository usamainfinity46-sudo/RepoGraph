# RepoGraph — One line changes

60-second typography-led product film, delivered in 16:9 and 9:16 at 60 fps.
The visual language is editorial: ivory, ink, cobalt, citrus and a restrained coral
failure state. Space Grotesk display type, IBM Plex Mono for evidence/code. Flat
solid fills only: no gradients, blur, soft shadows, faux 3D, floating UI cards or
ambient glow. Large kinetic type, moving signal paths, a mechanical approval gate,
and code rows that transform into the graph mark drive the movement. No stock
footage, generated people, fake chat testimonials or unsubstantiated promises.

| Seconds | Story | Motion |
| --- | --- | --- |
| 0–6 | One line changes. What else moves? | Macro code edit; ripple into a dependency system |
| 6–12 | RepoGraph. See the connections. | Graph resolves into the original graph-letterform mark |
| 12–20 | Trace the impact. | Indexing and evidence-backed dependencies in a workflow visualization |
| 20–28 | Choose tests with evidence. | Test files separate from source nodes; witness lines remain visible |
| 28–36 | You approve. Then it runs. | Prepared command, explicit approval and a controlled regression example |
| 36–44 | Local analysis. For your agent. | Flat source rows morph into graph connections; engine needs no LLM API key |
| 44–50 | MCP + Skill. | Two complementary components; proof from accepted release checks |
| 50–60 | Know the impact. Make your next move. | Clear, held install/setup commands and prerequisites |

All UI-like compositions are labeled workflow visualizations, not a claim that
RepoGraph ships a dashboard. The verification example uses a controlled fixture;
static suggestions do not imply exhaustive coverage. Test execution is opt-in and
requires approval. GUI clients have not been manually certified. Cross-platform
release evidence comes from docs/NPM_RELEASE_ACCEPTANCE.md.

The soundtrack is an original instrumental with synthesized keys/pads, a restrained
rhythm section and synchronized sound design. No voice clone, stock music license
or paid rendering service is needed. Type remains readable with sound muted.

Outputs live under dist/marketing/, outside Git. Source, font licenses, production
notes and render scripts remain in this directory. The film does not modify or
repackage the published npm release.
